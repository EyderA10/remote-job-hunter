# GetOnBoard Cover Letter Char Limit

The GetOnBoard application form limits the cover-letter field to **50-1000 characters**.
The 1-page .typ cover letter (~3.5k chars) cannot be pasted there.

Rule: for any posting whose application channel limits the cover-letter field (GetOnBoard
allows 50-1000 chars), draft a second, plain-text short letter alongside the full one and
save it as `output/cover_letters/<company>_<role>_<channel>.txt` (no markdown, plain
sentences, no signature block beyond a name/contact line). Check the actual char count
(`wc -c`) against the portal's stated limit before delivering; ~800 chars is a proven
working length.

Distill the short letter from the approved full letter's claims only - do not re-derive
claims or drop the honest-gap paragraph (it is the part that survives an interview).
